ゆかり
==============================================

「ゆかり」は、ホストが用意した音楽や動画を、参加者が手持ちのスマホやPCのブラウザから選んで流せるようにするツールです。  
ホストのPCに音楽・動画ファイルを置いておくだけで、参加者はその場で検索・リクエストでき、リクエストされた曲は順番に自動で再生されます。

# 目的
人が集まる場で、流す曲や映像をその場にいる人たち自身が選べるようにすること

- ホストは、音楽・動画ファイルを置いたWindows PCを用意するだけ。事前の曲登録作業は不要
- 参加者は、手持ちの端末のブラウザからカラオケのデンモクのように検索・予約するだけ。専用アプリのインストールは不要(スマホアプリ「ゆかナビ」からも利用可能)
- リクエストされた曲は順番に自動再生されるので、ホスト(機材係)が動作中にPCを直接操作する必要なし

# 使用例

## イベントで参加者がBGM・BGVを選ぶ
オフ会やパーティー、同人イベントのスペースなどで、ホストが持ち込んだ曲や映像を参加者がリクエスト。  
その場にいる全員でプレイリストを作りながら盛り上がれます。ニコ生風のコメントを画面に流すこともできます。

## お店で客がBGM・BGVを選ぶ
バーやカフェなどで、お店が用意した曲や映像をお客さんが自分のスマホから選んで流す、ジュークボックスのような使い方。  
接続URLとWiFi接続用のQRコードをまとめて表示できるので、お客さんへの案内も簡単です。

## カラオケ動画を持ち込んでカラオケをする
持ち込みカラオケで、参加者が自分のスマホから曲を検索・予約。  
キーチェンジ、OnVocal/OffVocalの切り替え、アニソンDB「ゆかりすたー」との連携、カラオケ配信への自動切り替えなど、カラオケ向けの機能も充実しています。

# 注意事項
流す音楽や映像の著作権・使用許諾などの権利関係は、主催者(ホスト)の責任で事前に解決しておいてください。  
特に店舗などで営利目的に使用する場合は、著作権管理団体への手続きなどが必要になることがあります。  
本ツールはリクエストと再生の仕組みを提供するものであり、コンテンツの権利処理は行いません。

# できること

## 用意するファイル
- 事前の登録作業不要。音楽・動画ファイルを入れたフォルダや媒体を用意するだけで使用可能(ファイル名に少なくとも曲名が付いていること)
- 動画ファイルだけでなく、音楽ファイル(mp3等)も再生可能
- 参加者の端末内の動画ファイルをアップロードしてリクエスト予約可能
- YouTubeのURLを指定してリクエスト予約可能 ※

## リクエスト予約
- 参加者が手持ちの端末のブラウザから曲や動画を検索してリクエスト予約
- 予約済みの曲は手動で順番の入れ替え可能
- 予約時に音声トラック、音ズレ補正、音量、ループ再生などを指定可能

## 再生
- リクエスト予約された曲を順番に自動再生。新規予約時は参加者が満遍なく選曲できるよう、キューへの挿入位置を自動で調整する機能あり
- 参加者が手持ちの端末から、音量調節・一時停止・音声トラック変更(OnVocal/OffVocal等)などをリモート操作可能
- 参加者が手持ちの端末から、ニコ生風にコメントを画面に流すことが可能

## カラオケ向け機能
- 予約時にキーチェンジ(移調)を指定可能
- mp3＋タイムタグ付き歌詞ファイルの組み合わせも使用可能
- アニソンDB「ゆかりすたー(ListerDB)」と連携し、作品名・歌手名・ファイル名等から検索可能
- 参加者がカラオケ配信曲を歌いたい場合は、「配信曲を歌う」とリクエストしておくと、自分の番になったときに配信の画面・音声へ自動切替

## マイページ機能
- 端末ごとに自動発行されるIDで、リクエスト履歴・お気に入り曲・「あとで歌う」リスト・お気に入り検索ワードを保存
- Google Drive連携でマイページのデータを複数端末間で同期 ※
- デバイスペアリングコードで別ブラウザ・別端末へアカウントを引き継ぎ

## 画面・操作性
- スマホで使いやすいモダンなUI
- ダークモード／ライトモード切り替え、文字サイズ変更に対応
- スワイプ操作対応の予約一覧
- 背景画像の設定(PC／スマホ別画像、カード・背景の透過度を個別調整)
- 接続情報ページ：接続URLとWiFi接続用QRコードをまとめて表示
- 専用スマホアプリ[「ゆかナビ」](https://ykr.moe/apps/yukanavi/index.html)(iOS / Android)からも、曲の検索・予約・予約一覧・プレイヤー操作・マイページを利用可能

※の機能はインターネット接続環境が必要

# 必要な環境

## 機材
- **Windows PC** — TV出力(HDMI出力)ができて、セカンダリモニタで動画を問題なく再生できる性能のもの。Atom系CPUのPCでなければ大抵動作する(それで動かなかったらWindowsのクリーンインストールを推奨)。BGMのみの用途であれば映像出力は不要
- **WiFiアクセスポイント** — ローカル運用時のみ必要。少人数ならスマホのテザリングでも可(オンライン接続機能利用時は不要)

あれば便利なもの
- **HDMIミキサー Blackmagic ATEM Mini シリーズ** — カラオケ配信とカラオケ動画の切り替えに使用

## ソフトウェア
- Web Server [XAMPP](https://www.apachefriends.org/jp/index.html)（PHP実行環境を含む）
- 動画Player [MediaPlayerClassic BE](http://sourceforge.net/projects/mpcbe/)
- 音楽Player [foobar2000](https://www.foobar2000.org/) with foo_httpcontrol [plugin](https://bitbucket.org/oblikoamorale/foo_httpcontrol/wiki/Home)
- ファイル検索ソフト [Everything File Search](http://www.voidtools.com/) — ゆかりすたーDB利用時は任意
- [ゆかりすたー / ゆっこビュー / 簡易キーチェンジャー](https://shinta.coresv.com/software/)（SHINTAさん作）
