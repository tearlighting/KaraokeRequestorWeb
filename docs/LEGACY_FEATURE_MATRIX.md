# Legacy to React feature matrix

Reviewed for Phase 15 against the visible navigation in `legacy/php/commonfunc.php` (`shownavigatioinbar*`), the linked Legacy pages/forms, the current React routes, Fastify routes and PHP endpoints. “API available” means a real endpoint exists; it does not imply the React UI uses it or that a module is Node-native.

## Priority proposal

1. User reservation history and “my requests” read view, reusing existing authenticated identity and privacy projection only after a dedicated contract is verified.
2. Admin playback/Agent diagnostics and queue Undo, after proving exact ordering and owner-fence behavior.
3. Frequently used safe settings, one field group at a time, retaining PHP as writer until an equivalent Node owner is deliberately adopted.
4. Comments, favorites and public exports after identifying their storage and moderation boundaries.
5. Keep optional BINGO, OAuth/Drive, DDNS, backups/restores and legacy updater out of the main migration path unless operators request them.
